# afterburnerr / desktop

Другой подход к профилю: рабочий стол в стиле Windows 98. Проводник содержит настоящие публичные репозитории; курсор запускает консоль, открывает диалог и вызывает короткий синий экран. GIF — постановочная сценка, а не запись настоящей операционной системы или текущего состояния git.

В `index.html` работает интерактивный прототип: Start, окна, закрытие/открытие, папки со ссылками на GitHub, остановка и повтор анимации. В GitHub используется GIF и обычные ссылки под ним; изображение само по себе не исполняет JavaScript.

Для reduced motion README выбирает статичный `desktop.png`. GIF: 18 секунд, 72 кадра, около 614 КБ. Вся графика собрана из HTML/CSS, без внешних изображений, шрифтов и сервисов.

Локально: `python3 -m http.server 18765`, открыть `http://localhost:18765/prototypes/c/`.

Это ветка-прототип. Основной профиль ещё не заменён.
