---

Это прототип, не новая версия опубликованного профиля. `index.html` содержит три работающие кнопки: кормить, стучать, усыплять. SVG самостоятельно проигрывает 12-секундную сцену и работает как изображение в GitHub README. Браузерные кнопки не выполняются внутри GitHub; возможная следующая версия использует Issue-команды и Actions для общего состояния существа.

Рисунок и анимация написаны с нуля: SVG, без внешних картинок, шрифтов и сервисов. Пересборка: `python3 build.py`.
